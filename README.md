# Название

## Используемые технологии
  * python
  * django
  * psycopg2
  * dotenv
  * ipython
  * Pillow

## Инструкция по развертыванию:

  * на основе файла .env.sample создать свой файл .env с настройками Джанго и Базы данных
  * фикстуры загружаются командой - python manage.py load_fixture
